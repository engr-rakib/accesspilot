# AccessPilot — Docker Technical Reference

> **Stack:** Nginx 1.25 + PHP 8.2-FPM (Debian 12)  
> **Backend:** LDAP + PowerShell WinRM (Exchange)  
> **Files:** `docker/Dockerfile` (55 lines), `docker/docker-compose.yml` (66 lines), `docker/nginx/default.conf` (60 lines)

---

## 1. Architecture

### Container Topology

```
Host: Linux (Ubuntu/Debian)
  │
  └── Docker Bridge Network: accesspilot_net
        │
        ├── Nginx Container (accesspilot_web)
        │   ├── Port: 80 + 443 directly (no host reverse proxy)
        │   ├── SSL cert: /data/secure/ssl/accesspilot.crt (self-signed, auto-generated)
        │   ├── Read-only root FS, tmpfs for /var/run + /var/cache/nginx
        │   ├── cap_drop ALL → cap_add NET_BIND_SERVICE, NET_RAW
        │   └── Serves: /public/, /resources/ (immutable cache)
        │
        └── PHP Container (accesspilot_php)
            ├── Port: 9000 (FastCGI, internal only)
            ├── Read-only root FS, tmpfs for /tmp
            ├── cap_drop ALL → cap_add NET_BIND_SERVICE, NET_RAW, DAC_OVERRIDE
            ├── LDAP → AD Domain Controllers (port 389)
            ├── PowerShell WinRM → Exchange Server (port 80)
            └── Mounts:
                ├── /data/secure → vault (users, license, LDAP config)
                ├── /data/logs   → audit logs, monitoring data
                ├── /var/www/html/app/ :ro
                ├── /var/www/html/bootstrap/ :ro
                ├── /var/www/html/config/
                ├── /var/www/html/public/ :ro
                ├── /var/www/html/resources/ :ro
                └── /var/www/html/App_Data/
```

### Request Lifecycle

```
Browser → Docker Nginx (443) → PHP-FPM (9000)
                                  │
                                  ├── LDAP (AD read/write)
                                  ├── PowerShell (Exchange WinRM)
                                  └── File I/O (/data/secure, /data/logs, App_Data)
```

**No host-level Nginx.** SSL termination, HTTP→HTTPS redirect, and reverse proxying to PHP-FPM are all handled inside the Docker Nginx container.

## 3. Docker Compose (`docker/docker-compose.yml`)

### Nginx Service

```yaml
nginx:
  image: nginx:1.25-alpine
  container_name: accesspilot_web
  ports:
    - "${APP_PORT:-80}:80"
    - "${APP_PORT_SSL:-443}:443"
  volumes:
    - ../public:/var/www/html/public:ro
    - ../resources:/var/www/html/resources:ro
    - ./nginx/default.conf:/etc/nginx/conf.d/default.conf:ro
    - /data/secure:/data/secure:ro
  command: >
    sh -c 'while [ ! -f /data/secure/ssl/accesspilot.crt ]; do sleep 1; done
    && exec nginx -g "daemon off;"'
  depends_on:
    - php
  networks:
    - accesspilot_net
  restart: always
```

Key points:
- Ports `${APP_PORT:-80}:80` and `${APP_PORT_SSL:-443}:443` — direct public access (default: 80 and 443)
- Nginx **waits** for the SSL cert to exist before starting (generated by PHP container's `generate-ssl-cert.php`)
- `/data/secure` mounted read-only for SSL cert access

### PHP Service

```yaml
php:
  build:
    context: ..
    dockerfile: docker/Dockerfile
  container_name: accesspilot_php
  environment:
    ACCESSPILOT_SECURE_BASE_PATH: /data/secure
    ACCESSPILOT_LOG_BASE_PATH: /data/logs
    AD_EXECUTION_MODE: remote
    CONTAINER_NAME: accesspilot_php
    IMAGE_NAME: docker-php
    NGINX_CONTAINER_NAME: accesspilot_web
    NGINX_IMAGE_NAME: nginx:1.25-alpine
  volumes:
    # Data mounts (host partitions — survive down -v)
    - /data/secure:/data/secure
    - /data/logs:/data/logs
    # Host partitions (monitoring)
    - /tmp:/tmp:rw
    - /home:/home:ro
    # App data mount
    - ../App_Data:/var/www/html/App_Data
    # Code mounts (bind, read-only)
    - ../app:/var/www/html/app:ro
    - ../bootstrap:/var/www/html/bootstrap:ro
    - ../config:/var/www/html/config
    - ../public:/var/www/html/public:ro
    - ../resources:/var/www/html/resources:ro
    - ../scripts:/var/www/html/scripts:ro
    # System monitoring
    - /sys/fs/cgroup:/host-cgroup:ro
    # PHP config mounts
    - ./php-error-logging.ini:/usr/local/etc/php/conf.d/error-logging.ini:ro
    - ./php-security.ini:/usr/local/etc/php/conf.d/security.ini:ro
  networks:
    - accesspilot_net
  command: >
    sh -c '
    install -d -o www-data -g www-data /data/secure
    && install -d -o www-data -g www-data /data/logs
    && install -d -o www-data -g www-data /data/logs/php_error_logs
    && chown -R www-data:www-data /data/secure/app_notifications 2>/dev/null || true
    && test -f /var/www/html/config/app.php
      && chown www-data:www-data /var/www/html/config/app.php
      && chmod 644 /var/www/html/config/app.php
    && php /var/www/html/scripts/generate-ssl-cert.php
    && php /var/www/html/scripts/resolve_exchange_hosts.php
    && exec php-fpm'
  restart: always
```

### Startup Sequence

1. `install -d` → ensure `/data/secure`, `/data/logs`, `/data/logs/php_error_logs` exist and owned by www-data
2. `chown` + `chmod` → fix notification state ownership; make `config/app.php` writable for `save_org()`
3. `generate-ssl-cert.php` → creates self-signed SSL cert at `/data/secure/ssl/accesspilot.{crt,key}` (if not exists)
4. `resolve_exchange_hosts.php` → auto-discover Exchange server FQDN → add to `/etc/hosts`
5. `php-fpm` → main process

Nginx container starts after PHP and waits for the SSL cert file to appear.

### Network

```yaml
networks:
  accesspilot_net:
    driver: bridge
```

Single bridge network. Ports 80 and 443 are exposed directly to the host.

## 4. Nginx Configuration (`docker/nginx/default.conf`)

```nginx
server {
    listen 80 default_server;
    server_name _;
    server_tokens off;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl http2;
    server_name _;
    server_tokens off;

    ssl_certificate     /data/secure/ssl/accesspilot.crt;
    ssl_certificate_key /data/secure/ssl/accesspilot.key;
    ssl_protocols       TLSv1.2 TLSv1.3;
    ssl_ciphers         HIGH:!aNULL:!MD5;

    root /var/www/html/public;
    index index.php login.php;

    client_max_body_size 10M;
    client_body_timeout 30s;
    client_header_timeout 30s;

    location /resources/ {
        root /var/www/html/public;
        expires 7d;
        add_header Cache-Control "public, immutable";
        add_header X-Content-Type-Options "nosniff";
    }
    location /assets/ {
        expires 7d;
        add_header Cache-Control "public, immutable";
    }
    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }
    location ~ \.php$ {
        fastcgi_pass php:9000;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include fastcgi_params;
        fastcgi_param PHP_VALUE "display_errors=off";
        fastcgi_read_timeout 120s;
    }
    location ~ ^/(app|bootstrap|config|scripts|App_Data)/ {
        deny all;
        return 404;
    }
    location ~ /\. {
        deny all;
        return 404;
    }
    location ~* (wp-admin|wp-content|wp-includes|xmlrpc\.php|phpmyadmin|adminer|\.env) {
        deny all;
        return 404;
    }

    access_log /var/log/nginx/access.log;
    error_log /var/log/nginx/error.log;
}
```

### HTTPS Redirect
Two-server block: port 80 returns 301 → HTTPS; port 443 handles SSL directly with self-signed cert from `/data/secure/ssl/`.

### Static File Caching
`/resources/` and `/assets/` files cached for 7 days with `immutable` and `X-Content-Type-Options: nosniff`.

### PHP Processing
FastCGI pass to `php:9000` with 120s timeout (long AD operations).

### Security Rules
- Deny app internals (`/app/`, `/bootstrap/`, `/config/`, `/scripts/`, `/App_Data/`) → 404
- Deny hidden files (`/.`) → 404
- Deny common attack paths (wp-admin, phpmyadmin, .env) → 404
- `server_tokens off` — no version in response headers
- `client_max_body_size 10M`

## 5. Bind Mount Strategy

### Volume Type: Bind Mounts (not named volumes)

All persistent data uses host bind mounts. This means:
- `docker compose down -v` is **safe** — host data unaffected
- No data is stored inside Docker's `/var/lib/docker/volumes/`
- Backup is a simple `tar` of host directories

| Host Path | Container Path | Content | Persistence |
|-----------|---------------|---------|-------------|
| `/data/secure/` | `/data/secure/` | Vault: users, license, LDAP config, roles, SSL certs | ✅ All compose ops |
| `/data/logs/` | `/data/logs/` | Audit logs, monitoring, PHP errors | ✅ All compose ops |
| `../App_Data/` | `/var/www/html/App_Data/` | Sessions, lock file, internal_admin | ✅ All compose ops |
| `../config/` | `/var/www/html/config/` | `app.php` (org config) | ✅ All compose ops |
| `../app/ :ro` | `/var/www/html/app/` | Application code | ❌ Re-deploy |
| `../public/ :ro` | `/var/www/html/public/` | Static assets | ❌ Re-deploy |
| `../resources/ :ro` | `/var/www/html/resources/` | Views, templates | ❌ Re-deploy |

### Permission Model

All vault/logs directories must be owned by **UID 33** (`www-data` in Debian):

```bash
sudo chown -R 33:33 /data/secure /data/logs
sudo chmod -R 770 /data/secure /data/logs
```

The container's `command` runs `install -d -o www-data -g www-data` as a safety net on every start.

```ini
session.use_only_cookies = 1
session.cookie_httponly = 1

session.cookie_samesite = Strict
session.gc_maxlifetime = 7200
session.sid_length = 48
session.sid_bits_per_character = 6
date.timezone = Asia/Dhaka
max_execution_time = 120
max_input_time = 60
memory_limit = 256M
upload_max_filesize = 10M
post_max_size = 10M
```

### Note on proc_open
`proc_open` is **disabled** in `php-security.ini`. The Exchange Kerberos ticket function (`exchange_ensure_kerberos_ticket()`) works around this by using temp files + `exec('ktutil < file')` instead.

## 9. Operations

### Code Update (via WinCP)

1. Upload entire project root to `/opt/accesspilot/`
2. Run: `sudo bash /opt/accesspilot/docker/deploy/post_upload_cleanup.sh`
3. Restart PHP: `sudo docker compose -f /opt/accesspilot/docker/docker-compose.yml restart php`
4. Restart Nginx: `sudo docker compose -f /opt/accesspilot/docker/docker-compose.yml restart nginx`

**Why Nginx restart required:** WinCP deletes old files (freeing inode) and creates new ones (new inode). Docker bind mount still points to old inode → container sees empty directory. Restart forces Docker to re-mount with new inode.

### Code Update (via Git)

```bash
cd /opt/accesspilot
git pull origin main
sudo docker compose -f docker/docker-compose.yml restart php
```

### Build & Start

```bash
cd /opt/accesspilot
sudo docker compose -f docker/docker-compose.yml build
sudo docker compose -f docker/docker-compose.yml up -d
```

### Rebuild (After Dockerfile change)

```bash
sudo docker compose -f docker/docker-compose.yml build --no-cache
sudo docker compose -f docker/docker-compose.yml up -d
```

### Stop/Start

```bash
sudo docker compose -f docker/docker-compose.yml down    # stop (data preserved)
sudo docker compose -f docker/docker-compose.yml up -d   # start
```

### View Logs

```bash
sudo docker compose -f /opt/accesspilot/docker/docker-compose.yml logs php --tail 50
sudo docker compose -f /opt/accesspilot/docker/docker-compose.yml logs nginx --tail 50
```

### Clear OPcache

```bash
docker exec accesspilot_php php -r 'opcache_reset();'
```

| Script | Purpose |
|--------|---------|
| `install.sh` | Full auto-installer (515+ lines): Docker install, build, SSL, UFW, fail2ban, systemd, kernel hardening |

> **Note:** `install.sh` installs a **host Nginx reverse proxy** + UFW + iptables + systemd service + health check cron. The current deployment uses `docker/deploy/harden.sh` instead for host-level security (no host Nginx, direct Docker ports).

## 12. Host-Level Security (Applied via `docker/deploy/harden.sh`)

### UFW Firewall Rules (ACTIVE)

```
Status: active
22/tcp       ALLOW IN    192.168.0.0/16          # SSH (LAN)
80/tcp       ALLOW IN    Anywhere                # HTTP
443/tcp      ALLOW IN    Anywhere                # HTTPS
Default: deny incoming
```

### iptables DOCKER-USER (EMPTY — intentional)

The DOCKER-USER chain is empty. In the direct-port architecture (Docker exposes 80/443 directly), DOCKER-USER must not block 80/443 — UFW handles access control. Previously added DOCKER-USER rules for 80/443 caused `ERR_CONNECTION_TIMED_OUT`.

### SSH Hardening

- `PermitRootLogin no`
- `PasswordAuthentication no`
- `MaxAuthTries 3`
- `AllowUsers` restricted to specific user

### Kernel Hardening (`/etc/sysctl.d/99-accesspilot.conf`)

- `rp_filter = 1` (reverse path filtering)
- `accept_redirects = 0` (disable ICMP redirects)
- `tcp_syncookies = 1` (SYN flood protection)
- `icmp_echo_ignore_all = 1` (disable ping)
- `somaxconn = 1024`, `tcp_max_syn_backlog = 2048`

## 13. Systemd Service (APPLIED)

Created via `docker/deploy/harden.sh` at `/etc/systemd/system/accesspilot.service`:

```ini
[Unit]
Description=AccessPilot Docker Stack
Requires=docker.service
After=docker.service network-online.target

[Service]
Type=oneshot
RemainAfterExit=yes
ExecStart=/usr/bin/docker compose -f /opt/accesspilot/docker/docker-compose.yml up -d
ExecStop=/usr/bin/docker compose -f /opt/accesspilot/docker/docker-compose.yml down
ExecReload=/usr/bin/docker compose -f /opt/accesspilot/docker/docker-compose.yml restart nginx
Restart=on-failure

[Install]
WantedBy=multi-user.target
```

> Containers auto-start on host reboot. Service is enabled and active.

## 14. SSL Certificate

The **self-signed SSL cert** at `/data/secure/ssl/accesspilot.{crt,key}` is generated by `scripts/generate-ssl-cert.php`:

```php
$pk = openssl_pkey_new(['private_key_bits' => 2048, 'digest_alg' => 'sha256']);
$csr = openssl_csr_new(['CN' => 'AccessPilot', 'O' => 'AccessPilot'], $pk, ['digest_alg' => 'sha256']);
$x509 = openssl_csr_sign($csr, null, $pk, 3650, ['digest_alg' => 'sha256']);
openssl_x509_export_to_file($x509, $crt);
openssl_pkey_export_to_file($pk, $key);
```

- Generated at **every container start** if the file doesn't exist
- Valid for **3650 days** (~10 years)
- Key file permissions: `0640`
- For public domains, replace with Let's Encrypt certbot

## 16. Troubleshooting

| Symptom | Cause | Fix |
|---------|-------|-----|
| Empty directory after WinCP | Inode change — Docker mount points to old inode | `docker compose restart nginx && restart php` |
| CSS/JS returns 302 instead of 200 | Same inode issue — Nginx sees empty mount | `docker compose restart nginx` |
| PHP can't write to vault | `/data/secure/` not owned by www-data (UID 33) | `sudo chown -R 33:33 /data/secure` |
| HTTP 500 / white screen | PHP error, missing config, LDAP extension | `docker compose logs php --tail 50` |
| 401 Unauthorized | Kerberos ticket expired | `docker exec accesspilot_php klist` |
| "Operation restricted" on POST | License not uploaded | Upload PEM at `index.php?page=license` |
| Build fails with DNS error | Container can't resolve hostnames | Add `--dns 8.8.8.8` to Docker daemon.json |
| Docker disk full | Unused images/layers | `docker system prune -f` |
| `proc_open()` disabled | PHP security config blocks it | Known — Exchange uses `exec()` fallback |
| HTTPS not working | SSL cert not generated | Check `docker compose logs php` for `generate-ssl-cert.php` errors |
| Nginx won't start | SSL cert missing at startup | Nginx waits for cert; check PHP container started successfully first |
| ERR_CONNECTION_TIMED_OUT | DOCKER-USER iptables blocking 80/443 | Clear DOCKER-USER: `iptables -F DOCKER-USER && netfilter-persistent save` |
