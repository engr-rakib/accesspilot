# Nginx Architecture — Container Deploy

## Overview

Nginx runs inside Docker (`accesspilot_web`) using the official `nginx:1.25.5-alpine` image. SSL termination, HTTP→HTTPS redirect, static file serving, and PHP-FPM proxying are all handled in-container. No host-level reverse proxy.

---

## 1. Deployment Model

| Aspect | Detail |
|--------|--------|
| Image | `nginx:1.25.5-alpine` (official, no custom Dockerfile) |
| Container | `accesspilot_web` |
| Config source | `docker/nginx/default.conf` mounted at `/etc/nginx/conf.d/default.conf:ro` |
| Ports (host) | `0.0.0.0:80` → container 80, `0.0.0.0:443` → container 443 |
| Network | `docker_accesspilot_net` (bridge), IP `172.18.0.3` |
| PHP backend | `172.18.0.2:9000` (FastCGI TCP) |
| SSL cert | `/data/secure/ssl/accesspilot.{crt,key}` (bind mount from host, read-only) |
| Restart policy | `always` |
| Uptime | 4+ days at time of writing |

### Docker Compose (nginx service)

```yaml
nginx:
  image: nginx:1.25-alpine
  container_name: accesspilot_web
  ports:
    - "${APP_PORT:-80}:80"
    - "${APP_PORT_SSL:-443}:443"
  volumes:
    - ../public:/var/www/html/public:ro
    - ../resources:/var/www/html/resources:ro
    - ./nginx/default.conf:/etc/nginx/conf.d/default.conf:ro
    - /data/secure:/data/secure:ro
  command: >
    sh -c 'while [ ! -f /data/secure/ssl/accesspilot.crt ]; do sleep 1; done
    && exec nginx -g "daemon off;"'
  depends_on:
    - php
  networks:
    - accesspilot_net
  restart: always
```

**Startup sequence:**
1. Container starts
2. Loops until `accesspilot.crt` exists (generated by PHP container's `generate-ssl-cert.php`)
3. Runs `nginx -g "daemon off;"` as PID 1

## 2. Nginx Configuration (`default.conf`)

### 2.1 Server Blocks

Two server blocks in a single file:

| Listen | Role |
|--------|------|
| `80 default_server` | HTTP → HTTPS redirect (301) |
| `443 ssl` (with `http2 on;`) | Main application server |
| `443 quic` | HTTP/3 (compiled but not enabled — needs UDP firewall) |

### 2.2 SSL Config

```nginx
ssl_certificate     /data/secure/ssl/accesspilot.crt;
ssl_certificate_key /data/secure/ssl/accesspilot.key;
ssl_protocols       TLSv1.2 TLSv1.3;
ssl_ciphers         HIGH:!aNULL:!MD5;
```

| Property | Value |
|----------|-------|
| Cert | Self-signed, 2048-bit RSA, SHA-256 |
| Valid | 3650 days (~10 years) |
| Protocols | TLSv1.2, TLSv1.3 only (no SSLv3, no TLSv1.0/1.1) |
| Ciphers | `HIGH:!aNULL:!MD5` (strong ciphers, no anonymous DH, no MD5) |
| Generated by | `scripts/generate-ssl-cert.php` at PHP container boot |

### 2.3 Rate Limiting Zones

```nginx
limit_req_zone $binary_remote_addr zone=login:10m rate=5r/s;
limit_req_zone $binary_remote_addr zone=api:10m rate=30r/s;
limit_req_zone $binary_remote_addr zone=static:10m rate=100r/s;
limit_conn_zone $binary_remote_addr zone=conn_limit:10m;
```

| Zone | Rate | Burst | Applied To |
|------|------|-------|------------|
| `login` | 5r/s | 3 | `/login`, `/auth` |
| `api` | 30r/s | 20 | PHP, main app |
| `static` | 100r/s | 50 | `/resources/`, `/assets/` |
| `conn_limit` | — | 10 conn/IP | API + PHP, 5 for login |

### 2.4 Location Blocks

```nginx
root /var/www/html/public;
index index.php login.php;
```

| Pattern | Behavior | Rate Limit | Cache |
|---------|----------|------------|-------|
| `/resources/` | Serve static, includes security headers | static zone (50) | 7d, immutable |
| `/assets/` | Serve static, includes security headers | static zone (50) | 7d, immutable |
| `/health` | PHP health check (nginx/php/ldap), no log | api zone (5) | — |
| `/nginx_status` | stub_status (internal only) | none | — |
| `/login`, `/auth` | PHP, strict rate limit, 1M body | login zone (3) | — |
| `/` | `try_files $uri $uri/ /index.php`, 1M body | api zone (20) | — |
| `\.php$` | `fastcgi_pass php:9000`, 120s timeout | api zone (20) | — |
| `app/, bootstrap/, etc.` | `deny all; return 404` | — | — |
| `.` (hidden) | `deny all; return 404` | — | — |
| `wp-admin\|phpmyadmin\|.env\|...` | `deny all; return 404` (20+ patterns) | — | — |

### 2.4 FastCGI Config

```nginx
location ~ \.php$ {
    fastcgi_pass php:9000;
    fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
    include fastcgi_params;
    fastcgi_param PHP_VALUE "display_errors=off";
    fastcgi_read_timeout 120s;
}
```

- Backend: `php:9000` (container DNS name → `172.18.0.2:9000`)
- SCRIPT_FILENAME: resolves to `/var/www/html/public/index.php`
- `display_errors=off`: production safety
- 120s timeout: accommodates long LDAP/PowerShell operations

### 2.5 Global Settings

```nginx
client_max_body_size 10M;
client_body_timeout 30s;
client_header_timeout 30s;
server_tokens off;
```

## 3. Request Lifecycle

```
Client → https://hostname/path
  │
  ├── DNS → 192.168.100.110:443
  │
  ├── docker-proxy (host → container)
  │     └── iptables DNAT → 172.18.0.3:443
  │
  ├── Nginx: server { listen 443 ssl }
  │     ├── SSL handshake
  │     ├── server_tokens off
  │     └── route by URI:
  │           ├── /resources/*   → file: /var/www/html/public/resources/*
  │           ├── /assets/*      → file: /var/www/html/public/assets/*
  │           ├── *.php          → FastCGI → php:9000
  │           ├── blocked path   → 404
  │           └── any other      → try_files → /index.php
  │
  ├── PHP-FPM (if .php)
  │     ├── LDAP (AD domain controllers, port 389)
  │     ├── PowerShell WinRM (Exchange, port 80)
  │     └── File I/O (/data/secure, /data/logs)
  │
  └── Response back through same chain
```

## 4. Security Measures

### Nginx-Level

| Feature | Implementation |
|---------|---------------|
| SSL only | Port 80 → 301 redirect, port 443 only |
| TLS version | TLSv1.2 + TLSv1.3 only |
| Server info leak | `server_tokens off` |
| Sensitive path leak | Return 404 (not 403) |
| Rate limiting | login(5r/s), api(30r/s), static(100r/s) zones |
| Body size limit | 10M global, 1M for login/main app |
| Request timeouts | 15s header, 15s body, 15s send |
| Error display | `display_errors=off` in FastCGI |
| Attack paths blocked | 20+ patterns (wp-admin, .env, .git, Dockerfile, etc.) |
| Exploit buffers | `client_body_buffer_size 128k`, fastcgi buffers tuned |
| Security headers | HSTS, X-Frame-Options, X-Content-Type-Options, X-XSS-Protection, Referrer-Policy, Permissions-Policy |
| SSL session cache | `shared:SSL:10m`, 10m timeout, no session tickets |

### Container-Level

| Feature | Implementation |
|---------|---------------|
| Read-only FS | Container `read_only: true` + tmpfs for runtime dirs |
| Capabilities | `cap_drop ALL`, only `NET_BIND_SERVICE` + `NET_RAW` |
| Healthcheck | `nginx -t` every 30s, 10s timeout, 3 retries |
| Log persistence | `/data/logs/nginx/` host mount, logrotate daily/30day |

### Host-Level (Applied via `docker/deploy/harden.sh`)

| Feature | Implementation |
|---------|---------------|
| UFW firewall | SSH(LAN) + HTTP + HTTPS, default deny incoming |
| systemd service | Auto-start containers on boot |
| fail2ban | 3 nginx jails (http-auth, botsearch, brute-force) |
| logrotate | Daily, 30 day retention, compress, nginx -s reopen |
| DOCKER-USER | Empty (intentional — UFW handles access control) |
