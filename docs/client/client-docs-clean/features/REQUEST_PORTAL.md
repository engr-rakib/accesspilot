## The "Wow" Features

### Let Anyone Submit — No Login Required

Share the link. Your team opens it. They fill in what they need. No account creation. No training. The portal is one page, one form, instantly understandable.

### Choose From 20+ Request Types

Unlock users. Reset passwords. Enable mailboxes. Add email addresses. Create distribution groups. Set mail tips. Hide from address lists. Enable archives. Everything your team needs — all in one dropdown.

### Smart Fields That Adapt

Select "Add Email Address" and an email field appears. Select "Create Distribution Group" and group name fields show up. The form changes based on what you need — no clutter, no confusion.

### Requests Arrive Ready for Action

Every submission lands in your admin dashboard with full context: who requested it, what domain, what action, any extra details. One click to approve and execute. The system runs the change automatically.

### Track Everything

Every request has a timestamp, status, and execution history. No more "did you do that?" conversations. The proof is right there.
